# Screenshots to add

Drop images in this folder using the filenames below, then update the
"Screenshots" section in the main `README.md` to display them (a commented
example is already there).

Recommended size: 1280–1600px wide, PNG or JPG. Use demo/seed accounts
only — never a real Client's API keys, real end-user data, or real
domain names. Blur or redact anything in a screenshot that shows an
actual key/secret value, even a demo one, since people screenshot-copy
habits.
